Compatibilité native Google Sites (Bac à sable iframe)

Cette application intègre un gestionnaire de mémoire résilient (safeStorage) : lorsque Google Sites bloque localStorage dans son iframe sécurisée, GeriaFlow bascule automatiquement en mémoire vive sans erreur et reste 100 % utilisable.

  1. Ouvrir votre site Google Sites : Créez une nouvelle page (ex. « Pré-test GeriaFlow ») et choisissez le thème sobre sans en-tête encombrant.
  2. Insérer le code HTML : Dans le panneau latéral droit, cliquez sur Insérer → Intégrer (Embed), puis sélectionnez l'onglet Code intégré (Embed code).
  3. Coller le fichier unique : Collez l'intégralité du code de geriaflow_v04.html, cliquez sur Suivant puis Insérer.
  4. Ajuster les dimensions : Étirez les poignées latérales du bloc sur 100 % de la largeur (12 colonnes) et réglez la hauteur verticale sur 850 px à 1 000 px. Publiez la page.
  5. Tester sur plusieurs appareils simultanément (Optionnel) : Si l'aidant saisit sur son smartphone et que le médecin regarde sur son PC en même temps, renseignez l'URL et la clé Anon de votre projet Supabase dans l'onglet précédent sur chaque appareil.
